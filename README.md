# MIT 8103: Advanced Database Systems Practical Portfolio

# Project Title

University Student Result Management System

# Project Overview

This project demonstrates the application of advanced database concepts through a simulated University Student Result Management System. It uses PostgreSQL for relational database operations and MongoDB for NoSQL data management and explores query optimisation, transaction management, and distributed cloud databases.

# Portfolio Contents

# Portfolio 1: Database Design and Modelling

Database schema, entity relationships, tables, keys, and constraints.

# Portfolio 2: Query Processing and Optimisation

SQL queries, joins, query execution plans, and indexing analysis.

# Portfolio 3: Transactions and Concurrency

Transaction control, COMMIT, ROLLBACK, and transaction isolation concepts.

# Portfolio 4: NoSQL and Advanced Data Models

MongoDB documents, aggregation pipelines, filtering, grouping, and comparison with PostgreSQL.

# Portfolio 5: Distributed and Cloud Databases

MongoDB Atlas cloud deployment, replica-set configuration, monitoring, backup options, and analysis of sharding, availability, and consistency.
